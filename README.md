E-Commerce Customer Segmentation & RFM Analytics

Hi! Welcome to my Data Analytics portfolio project. In this project, I built an end-to-end analytics Project to help an e-commerce business understand their customer behavior and improve retention rates. 

Project Objective
The goal was to analyze transaction data and segment customers based on their purchasing habits using the **RFM (Recency, Frequency, Monetary)model. By identifying "Champions" and "At-Risk" customers, the business can optimize their marketing strategies.

Tools & Technologies Used
1. Python (Pandas, NumPy):Used for data generation, cleaning, and calculating the mathematical RFM scores.
2. Power BI: Designed an interactive dashboard to visualize the customer segments and revenue distribution.
3. Data Visualization:** Created Donut Charts, Treemaps, and Scatter Plots to make insights easily digestible for stakeholders.

 Key Insights & Dashboard Features
1. RFM Value Matrix: A scatter plot mapping Customer Spend against Recency (Days since last purchase), highlighting the exact clusters of our customer base.
2. Segment Distribution: A clean Donut Chart displaying the percentage breakdown of all 6 customer segments (Champions, Loyal, At-Risk, Hibernating, etc.).
3. Revenue Impact: A Treemap that instantly shows which customer segment brings in the highest total sales.
